من نحن

رمشة بلس جهة متخصصة في تصميم وتطوير مواقع الويب، ونقدم خدمات إنشاء المواقع وتعديلها وتطويرها وإضافة الصفحات والأقسام والمميزات حسب احتياج العميل.

سياسة الخصوصية

جمع المعلومات

قد نحتاج إلى بعض المعلومات التي يقدمها العميل عند التواصل معنا أو طلب إحدى خدمات تطوير المواقع.

استخدام المعلومات

تستخدم المعلومات اللازمة للتواصل مع العميل وتنفيذ الخدمة المطلوبة وتقديم الدعم.

حماية البيانات

نحرص على التعامل مع بيانات العملاء بشكل مناسب وعدم استخدامها خارج الغرض المرتبط بالخدمة.

سياسة الاسترجاع

قبل بدء العمل

يمكن للعميل التواصل معنا لطلب إلغاء الخدمة قبل البدء في تنفيذها.

بعد بدء التنفيذ

تختلف إمكانية الإلغاء أو الاسترجاع بحسب مرحلة تنفيذ الخدمة والأعمال التي تم إنجازها.

وجود مشكلة

في حال وجود مشكلة مرتبطة بالخدمة المتفق عليها، يرجى التواصل معنا لمعالجة المشكلة.

الشروط والأحكام

1. نطاق الخدمة

يتم تنفيذ خدمات تصميم وتطوير المواقع وفق التفاصيل التي يتم الاتفاق عليها مع العميل.

2. محتوى العميل

العميل مسؤول عن توفير المحتوى والمعلومات المطلوبة لتنفيذ المشروع متى كان ذلك مطلوبًا.

3. مدة التنفيذ

تختلف مدة تنفيذ الخدمة حسب حجم المشروع والمتطلبات والتعديلات المطلوبة.

4. التعديلات

يتم تحديد نطاق التعديلات ضمن تفاصيل كل طلب قبل بدء التنفيذ.

5. التواصل

يمكن للعميل التواصل معنا عبر قنوات التواصل الموضحة في الموقع للاستفسار أو متابعة الطلب.
